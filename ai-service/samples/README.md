# Demo video samples

Put local `.mp4` clips here for demo mode and for
`python -m app.tools.local_video_check ./samples/<clip>.mp4`.

Video files are intentionally not committed (see `.gitignore`); only this note is.
Point `DEMO_VIDEO_PATH` in `ai-service/.env` at a clip in this folder, or use
`DEMO_VIDEO_PATHS_JSON` to map one clip per camera id.
